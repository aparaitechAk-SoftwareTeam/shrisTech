BBS Gold - Windows Testing & App Review Guide

This comprehensive document is intended for team members who operate on a Windows OS but need to verify app functionality and process the physical iPhone Screen Recording required by Apple App Store Review.

Important Context: Apple App Review recently rejected the build under Guideline 2.1 due to an initialization crash on iOS devices. The codebase has been fully patched. Because building an iOS application natively via USB is banned by Apple on Windows machines, this guide executes functionality testing via Web Browser and completes the iOS submission via TestFlight.

Part 1: Windows Environment Setup

To successfully verify the app code on your local Windows laptop, you must install the Flutter software development kit.

1. Download & Install Flutter SDK

  • Navigate to the Flutter Windows Download Page.
  • Download the latest stable Flutter SDK .zip file.
  • Extract the contents to a location like C:\flutter (Do not extract it into Program Files).

2. Add Flutter to your Environment Variables

  1. Click the Start menu and type Environment Variables, select Edit the system environment variables.
  2. Click the Environment Variables... button.
  3. Under "User variables for [Your Name]", double-click the row titled Path.
  4. Click New and type: C:\flutter\bin
  5. Click OK on all windows to save. Restart your computer (or close and re-open all your terminal windows).

Part 2: Project Installation & Dependencies

Once you have extracted the corrected App-Corrected.zip codebase, open your Command Prompt (or PowerShell).

# Inside your terminal, navigate to the extracted frontend folder:
cd "C:\Path\To\BBS_Gold_Project\App"

# Clear out any leftover cache dependencies
flutter clean

# Download and install the fresh packages for the app
flutter pub get

Part 3: Testing App Functionality Locally on Windows

Because you are on a Windows machine, you cannot test Apple iOS code directly via USB. Instead, use Google Chrome to instantly verify all app functions, buttons, and API flows.

  1. Ensure you are still inside the project folder in your terminal.
  2. Run the following command: 
    flutter run -d chrome
  3. The BBS Gold app will heavily optimize and launch directly inside your Google Chrome or Edge browser.
  4. Log into the application and click through the Dashboard, Cart, and Settings to verify the platform code is 100% stable.

Part 4: The iPhone Screen Recording Process (Apple Request)

Requirement Reminder: Apple App Review has requested a physical-device screen recording. Since Windows users cannot tether an iPhone via USB for Xcode, you will use your team's Cloud/TestFlight pipeline.
  1. Trigger TestFlight Build: Upload this newly fixed codebase to your automated cloud deployment platform (such as GitHub Actions, Codemagic, etc.) just as your team did originally.

    🚨 CRITICAL MAC / PIPELINE STEP FOR SWIFT PACKAGE MANAGER: Because this app uses Swift Package Manager instead of CocoaPods, whoever opens this project on a Mac (or your CI/CD pipeline) MUST run flutter clean, flutter pub get, and flutter build ios --config-only in the terminal before opening Xcode. This correctly activates SPM inside the Xcode pipeline.

  2. Download on iPhone: Once the cloud finishes uploading, open the TestFlight app on your physical iPhone and download the newly processed "Ready to Test" version over Wi-Fi.
  3. Record the Screen: Open the iOS Control Center (swipe down from top right) on your iPhone and start a Screen Recording.
  4. Navigate the App: The launch crash is now eliminated. Slowly and clearly navigate through the exact flow Apple requested without visual cuts:
    • App Launch
    • Login to an existing account
    • Dashboard
    • Stock / Catalogue (View the product lists)
    • Product Details (Tap on at least one product)
    • Orders & Order History
    • Profile View
    • Logout
    • Registration & Account Deletion Flow (if applicable).
  5. Save & Send: Stop the screen recording and save the video file. Log into the Apple App Store Connect system online, go to the active Resolution Center thread for Guideline 2.1, and attach this physical iPhone screen recording video!
